# Feature status

Legend: **IMPLEMENTED** = code exists and was run against the real backend; **TESTED** = covered by automated
tests (evidence named); **NOT_AVAILABLE** = the backend does not provide it, the UI shows an honest "Not
available yet" state with no controls. "Unit/Comp" = Vitest, "E2E" = Playwright against the real local
backend (offline unless stated).
