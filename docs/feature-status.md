# Feature status

Legend: **IMPLEMENTED** = code exists and was run against the real backend at least manually/E2E;
**TESTED** = covered by automated tests (evidence given); **NOT_AVAILABLE** = backend does not provide it, UI
shows an honest "Not available yet" state with no controls. "Unit/Comp" = Vitest, "E2E" = Playwright against
the real local backend.
